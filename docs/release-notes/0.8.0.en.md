# Chaosfolk 0.8.0 alpha

You can now choose the depth of a product audit, remove tests and follow their
progress in a local dashboard. This release also fixes scan stopping and the
protection of reports prepared for sharing.

## Choose tests and set limits

Quick selects the highest-priority checks, Standard adds more cases and Deep
selects all 116 tests in the catalog. Each depth covers the whole product.
Chaosfolk adapts the tests to the features discovered in your app; a check that
requires a missing account or tool stays marked as blocked.

Uncheck any tests you want to exclude. Your choices remain saved when you change
depth. During the scan, follow results and elapsed time, with limits on duration,
actions and open browsers. The browser limit defaults to six.

![Scan settings in the Chaosfolk dashboard.](../../assets/audit-scan.gif)

AI usage appears when your coding assistant supplies measurements. Otherwise,
it remains unavailable. Refreshing the dashboard makes no AI calls.

## Keep control of the scan

The Stop button stays accessible during a save and at the bottom of the test
list. A delayed start request can no longer restart a scan you have just stopped.
On resume, interrupted tools return to the queue with their observations saved.

Your limits stay in the form if a save fails, even after a reload. Changes to
different fields in two tabs no longer overwrite each other. Chaosfolk closes
finished independent users' browsers before opening the next batch, and closes
external programs when tests finish.

A request already sent to the AI may keep consuming usage after stopping.
Cancellation depends on the assistant running the agents.

## Understand and share results

The report distinguishes finished, excluded, blocked and pending tests. An
incomplete audit has a provisional score; no numeric score appears before the
first result. Agents retain all pages they discover in parallel.

Copies prepared for sharing remove raw observations and replay diagnostics that
may contain entered values. Details stay in the private session with restricted
access. Scenario export is refused when it contains a sensitive check or a
recognized authentication link. Review older scenarios before sharing them.

Large reports load details on demand. Several operations use disk storage to
reduce the memory used by long sessions.

## Check whether a problem reproduces

Replay a journey on test data reset to a verified state before each trial, and
compare it with a reference journey. The report shows failures among valid
trials: one failure out of five stays distinct from five failures out of five.
An execution error counts as an invalid trial.

Page probes and accessibility checks now reject redirects, including redirects
within the same site. Supply the final authorized URL; otherwise, the result
remains inconclusive.
