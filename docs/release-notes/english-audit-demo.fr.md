# Démonstration de l’audit produit en anglais

Le GIF de l’audit produit et son image fixe dans le README affichent désormais
les libellés en anglais : profondeur, sélection des tests, état et limites de
consommation.

Le script applique ces traductions à chaque capture. Il utilise une vraie session
locale et vérifie les sélections et les limites enregistrées dans SQLite. L’audit
ne démarre pas pendant la capture ; aucun résultat de test ni estimation de
consommation d’IA n’est affiché. Ces traductions concernent la démonstration ; le
tableau de bord utilisé en direct conserve sa langue actuelle.

Chaque release aura des notes en français et en anglais, avec des liens vers les
deux versions dans le README et le changelog.
