# Image generation prompts

Both assets were generated with the built-in image generation tool and transparent backgrounds. The second used the first as its character reference. The PNGs are consumed directly, without a raster edit step.

## Main companion

```text
Use case: logo-brand. Asset: original AI companion mascot logo for Chaosfolk, an open-source tool whose playful simulated users test web apps. Create one centered head-and-shoulders mascot, isolated on genuine transparent background. A charming small lime-green imp creature with a rounded squircle head, two short asymmetric pointed ears, huge dark expressive eyes with tiny ivory highlights, one small crooked smile, a little lightning-shaped tuft. Friendly mischief, curiosity, bold recognizable silhouette. Flat clean editorial sticker illustration with thick deep forest-green outlines, minimal 2-tone shading, lime #dcf78b and dark forest #101612, small warm orange accent. Readable as a 48px avatar and GitHub logo. Original character, no resemblance to existing mascot franchises. No letters, no words, no background, no border frame, no watermark, no complex texture. Generous transparent padding; entire character visible.
```

## Profile atlas

```text
Use case: identity-preserve. Asset: one production sprite atlas for the Chaosfolk audit UI. Use the attached mascot as the exact character identity and style reference. Create a clean 4-column by 3-row grid of TWELVE head-and-shoulder avatar skins of this SAME lime imp companion. Transparent background, no grid lines, no labels or text. The output canvas must be 4:3 aspect ratio. Every cell equal size, each head centered exactly in its cell with at least 12% clear padding, complete ears visible, no overlap between cells. All characters retain the same lime-green face, asymmetric ears, huge dark eyes, lightning tuft and dark forest outline. Only change facial expression and a single personality accessory, using restrained coral, mint, violet and orange accents. Reading order: row1 col1 curious newcomer wide eyes small backpack straps; col2 impatient sporty orange headband and raised eyebrow; col3 focused keyboard enthusiast rectangular glasses and headphones; col4 mobile user with cap backwards and small smartphone near cheek. Row2 col1 careful reader round reading spectacles and calm eyes; col2 puzzled jargon skeptic one raised brow and single question-mark-shaped curl (no printed punctuation); col3 distracted daydreamer eyes glancing sideways and crooked beanie; col4 detail checker with magnifying glass beside cheek. Row3 col1 cautious shy creature in high collar with nervous smile; col2 explorer with small outdoor hat and confident grin; col3 multitasker with two colored hair clips and energetic eyes; col4 text-focused attentive creature with monochrome scarf and calm expression. Make each expression unmistakable at 64px. Consistent sizes, clean flat sticker illustration, minimal shading, preserve alpha, no shadows outside cells. This atlas is one UI asset, not a presentation slide.
```
